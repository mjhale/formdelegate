# Lato

Unmodified Lato Bold, Bold Italic, Black, and Black Italic fonts downloaded from
Google Fonts' official repository on 2026-10-28:
https://github.com/google/fonts/tree/main/ofl/lato

These retain the app's existing 700/900 normal/italic choices. Bundling the fonts
with `next/font/local` removes the build-time Google Fonts request. The complete
font files also preserve glyph coverage without depending on remote subsets.
